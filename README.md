# Personal Projects

Raccolta di progetti accademici e personali su machine learning, NLP, computer vision, sviluppo web e mobile, cybersecurity, testing e progettazione dell'interazione.

## Struttura del repository

```text
Personal-Projects/
|-- BlastocystAnalyze/                         repository collegato per l'analisi di blastocisti
|-- Bugzilla/                                  classificazione di issue Mozilla e pipeline MLOps
|-- ExoplanetsClustering/                      clustering e classificazione di esopianeti
|-- HateSpeechDetector/                        classificazione della tossicità del testo
|-- Ingegneria del Software/                   applicazione Flask The Verifiers
|-- Integrazione e Testing/                    documentazione e materiale di collaudo
|-- Modelli e Metodi per la Qualità del Software/
|-- Not_Inclusive_ClassifierRewriter/          FAIR ISLE: classificazione e riscrittura inclusiva
|-- Progettazione Interazione Utente/          ricerca utente, prototipi e presentazioni
|-- Rans0mWar3 - CyberSecurity/                esercitazione su RSA e Fernet
|-- Sviluppo Mobile Software/                  documentazione e materiali di AsilApp
|-- TennisMatchPrediction/                     predizione di incontri ATP
`-- Tesi Computer Vision + Machine Learning/   pipeline YOLO per immagini in ambito sicurezza
```

## Progetti

| Directory | Contenuti principali | Tecnologie e formati |
|---|---|---|
| [BlastocystAnalyze](./BlastocystAnalyze) | Repository collegato dedicato alla previsione della vitalità embrionale da sequenze time-lapse. | Deep learning, computer vision |
| [Bugzilla](./Bugzilla) | Pacchetto `naplace`, API FastAPI, interfaccia Gradio, modelli TF-IDF/GRU/LSTM/SetFit, pipeline DVC, test, Docker e monitoraggio. | Python, FastAPI, Gradio, DVC, Docker, Prometheus |
| [ExoplanetsClustering](./ExoplanetsClustering) | Sei notebook per audit, preprocessing, EDA, clustering, interpretazione, classificazione supervisionata e produzione di tabelle e figure. Include dataset, report PDF e presentazione. | Python, Jupyter, pandas, scikit-learn |
| [HateSpeechDetector](./HateSpeechDetector) | Notebook di addestramento e valutazione, modello Transformer locale e interfaccia Flask per la classificazione della tossicità. | Python, PyTorch, Transformers, Flask |
| [Ingegneria del Software](./Ingegneria%20del%20Software) | Applicazione web The Verifiers con viste utente e amministratore, integrazione MySQL e risorse frontend. | Python, Flask, MySQL, HTML, CSS, JavaScript |
| [Integrazione e Testing](./Integrazione%20e%20Testing) | Specifica di integrazione e testing e directory dedicate alle attività di test. | DOCX, materiale di collaudo |
| [Modelli e Metodi per la Qualità del Software](./Modelli%20e%20Metodi%20per%20la%20Qualit%C3%A0%20del%20Software) | Report finale, diario di progetto e versioni successive dei diagrammi di Gantt. | DOCX, XLSX, PDF |
| [Not_Inclusive_ClassifierRewriter](./Not_Inclusive_ClassifierRewriter) | FAIR ISLE: notebook per preprocessing, classificatori e riscrittori in italiano, inglese e multilingua; metriche, servizio e web app Flask. Dati e modelli sono gestiti tramite DVC. | Python, Jupyter, Transformers, Flask, DVC |
| [Progettazione Interazione Utente](./Progettazione%20Interazione%20Utente) | Documentazione UX, sette interviste, prototipi a bassa e alta fedeltà e presentazioni FitMate/The Verifiers. | DOCX, PPTX, immagini |
| [Rans0mWar3 - CyberSecurity](./Rans0mWar3%20-%20CyberSecurity) | Generazione di chiavi RSA e decifratura didattica di file protetti con uno schema ibrido RSA/Fernet. | Python, pycryptodome, cryptography |
| [Sviluppo Mobile Software](./Sviluppo%20Mobile%20Software) | Materiali tecnici, manuale utente, video e contenuti promozionali di AsilApp. La directory `AsilApp/` non contiene file tracciati. | PDF, MP4 |
| [TennisMatchPrediction](./TennisMatchPrediction) | Feature engineering temporale, baseline, confronto fra modelli, valutazione e stacking per incontri ATP; report e grafici in `outputs/`. | Python, pandas, scikit-learn, matplotlib |
| [Tesi Computer Vision + Machine Learning](./Tesi%20Computer%20Vision%20%2B%20Machine%20Learning) | Web scraping, notebook di addestramento per armi, bandiere e persone, pipeline YOLO e metriche di valutazione. | Python, Jupyter, Ultralytics YOLO, BeautifulSoup |
